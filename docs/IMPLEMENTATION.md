# 当前实现与设计基线对照

2026-11-02 · 0.1.0预发布工程 · 当前批次N2（数据层）

## 已写入代码

前台浏览与文本编辑生命周期沿用首批实现。认证现为next-auth 4.24.15稳定版，直接依赖精确锁定。技术选择与目标数据流见[ARCHITECTURE.md](ARCHITECTURE.md)，N2详细变更与证据见[verification/2026-11-02-data-layer.md](verification/2026-11-02-data-layer.md)。

Prisma现有29个模型，补齐冻结设计所需的三层媒体/分类标签引用、搜索、任务及备份记录。内容事务已同步草稿/新历史/当前发布引用、搜索和Outbox；使用按内容行锁及相同幂等键锁。引用检查与删除前保护服务已写，但管理删除路由和物理对象清理尚未接通。

公开查询已独立，不再include草稿与全部历史；按ID/path读取当前发布，列表/搜索在数据库内做权限过滤、筛选、基础相关性和签名游标。公开分类/标签从真实公开引用查询。只读事务和statement_timeout已写入代码，尚无真实数据库执行证据。本地样例仍是单独只读适配器。

## 不能认定已完成的部分

- 没有数据库、迁移、真实管理员或生产部署。29个Prisma模型不等于物理库已建好；跨表/部分唯一/不可变保护等见[物理约束清单](../prisma/CONSTRAINTS.md)，必须另做真实SQL和权限验证。
- 媒体上传、Sharp/S3处理、受控派生图响应和GC未接通；编辑UI尚无完整分类/媒体管理。服务端可验证并保存已有合法引用，不再一律拒绝非空引用，但真实资源初始化条件尚未具备。
- 分类标签管理、全局改名后的投影同步、后台列表/历史分页、公开目录分页等尚未完整覆盖工作契约。当前公开目录读取真实引用，但不是完整分类管理实现。
- 中文搜索已有数据库基础包含匹配与相关性分页，pg_trgm/短词专用策略与性能尚未完成；不再把JavaScript全量匹配作为生产实现。
- operation_jobs/outbox和备份等只有模型，Outbox已有状态事件写入；没有Worker、租约认领/消费/重试、导出、分级备份或恢复执行。
- 账号首次初始化、MFA绑定/恢复、成功登录与会话撤销、敏感动作重新认证仍待实现/联调；不再存在会话adapter选型分支。

## 契约与配置

[contracts/openapi.yaml](../contracts/openapi.yaml)仍描述完整V1.0目标（技术修订1.0.1），不是当前操作覆盖率声明；未完成模块返回503。原冻结设计文件不覆盖。

CURSOR_SECRET是独立的生产分页签名密钥，不能再依赖AUTH_SECRET兼任；开发只读预览允许临时fallback。游标格式已版本化，旧游标400后从第一页重新进入。日期存储精度为毫秒，避免分页边界精度丢失。
