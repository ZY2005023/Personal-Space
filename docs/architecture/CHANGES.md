## TECH-006：N6恢复登录后换绑（2026-11-03）

业务工作契约1.0.2保持36路径/49操作/558引用；安全契约为8操作/80引用。N5记录中的最后一枚恢复码缺口在代码和替身中闭合，真实环境仍属于IV-01/02/05/06待验证。
