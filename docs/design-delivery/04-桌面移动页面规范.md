# Personal Space V1.0 桌面与移动高保真页面规范

版本 UI-1.0｜2026-11-02｜正式静态设计交付

## 1. 文件与适用范围

04-页面原型/ 内每个页面有 SVG 可编辑源文件及对应 PNG 预览。D 前缀为桌面1440宽、M为手机390宽，具体高度见画板清单.json；两张00总览是缩略索引。SVG可在支持SVG的设计工具中编辑，不宣称已经创建Figma文件。页面均为静态设计，不含运行网站、应用代码、真实账号或真实内容；样片为本次原创矢量插图，不是用户已上传的照片。

原记录只冻结布局和交互原则，未提供完整视觉源文件。配色、字号、尺寸和示例文案是本次交付细化，沿用极简阅读、文字首页、规则相册封面和自由详情布局。04不为原记录未确认的AI/兴趣/社交功能增加入口。

## 2. 视觉系统

背景#F7F6F2，正文#252D2B，次级文字#646D68，主操作#245744，弱强调#E7EDE6，边界#DADDD5，错误#A3372D，表面#FFFFFF。错误同时给出文字，不仅靠颜色；最终对比度及渲染在IV-08实测。字体Microsoft YaHei，回退PingFang SC、Noto Sans CJK、sans-serif。电脑主标题38–48，手机26–34；正文电脑17/34、手机17/32–36；辅助12–14/20；按钮14，粗体700。

间距8为基础，4为微调；常用16/24/32/48/64。按钮和输入框44–46高，圆角6；内容卡圆角8，主弹窗10；边框1，阅读页避免大面积卡片。实际触控区域≥44×44，即使画板小字链接也要扩展点击区域；静态PNG不能证明可点击面积和读屏语义已实现。

桌面公共最大内容宽1080，页边180；阅读正文700–840，知识目录在右侧独立约180宽，顶部进度3高。桌面后台侧栏224，主区左起264，主操作对齐顶部右侧。1440编辑左右530/550，间隔20；发布设置按需显示右侧面板，开启时压缩/切换预览，不覆盖未保存输入。

手机390页边24，后台20；主内容342/350宽，单栏。顶部公共72、后台64；抽屉310宽。编辑底部固定操作区100含安全区，正文加等高底部padding，软键盘时输入不被遮挡。360–430范围保持至少20边距，按钮必要时整行；768–1023使用单栏编辑与抽屉，≥1024才启用桌面导航/双栏。200%缩放不依赖固定画板宽度，实际自适应属于IV-05。

## 3. 画板目录与规格

- 01首页：纯文字首屏→生活/知识→最新→精选；数据GET /contents，不显示私密摘要。精选取公开相册cover placement，是否另有指定精选配置无旧记录依据，暂不增管理功能。
- 02生活知识列表：模块、分类与标签筛选，卡片类型明确，分页游标沿用筛选；GET /contents、/categories、/tags。画板展示知识变体，生活同版式但容纳MOMENT/ARTICLE/ALBUM。
- 03文章：顶部阅读进度、标题日期、正文、桌面知识目录；手机折叠目录按钮控制展开区。生活文章同阅读样式，目录按标题层级有则显示。GET /contents/{id}。
- 04相册列表：桌面规则三列封面，手机两列；封面区域同尺寸，title和数量不压图；05相册详情自由布局，但DOM与视觉阅读顺序一致；06大图支持前后、关闭、计数及说明，不展示原图下载。派生图请求必须绑定contentId+placementId。
- 07搜索：q输入、命中数量文案、结果摘要；只有服务端确实给总数才展示精确数，本契约未返回总数，实际默认显示“搜索结果”，画板的3条为示例数据集计数。短字查询和输入法组合事件不能重复提交；提交后保留关键词。
- 08概览：内容/草稿/相册计数由管理列表的同权限聚合计算；本契约未设额外dashboard接口，不假造独立数据源，初版可只显示可准确计算的数量。备份三状态独立，09列表显示草稿标题和当前状态，两者不能混成一个版本。
- 10文章编辑：桌面Markdown/实时预览，保存状态显示最后成功时间，手机编辑/预览切换保留输入和滚动位置。标题编辑入口与29设置面板补齐；未保存时发布按钮先要求保存，再取新ETag。
- 11相册编辑：照片项独立placementId，拖动和上移下移都修改数组顺序；移除只是移除引用，不删除原图；多次使用相同媒体允许不同说明。两次相同图用不同项显示。
- 12发布确认：标题、可见性、地址、草稿/线上版本摘要、媒体状态；点击确认才POST /publish。禁止把“保存草稿”做成隐式发布。按钮提交中禁用，超时提示核查任务结果，用原幂等键重试。
- 13历史：区分快照序号/正式发布序号，恢复动作先确认“只替换草稿”，再检查草稿ETag。可通过详情读取快照进行比较；不展示修改历史版本按钮。
- 14媒体：上传中/处理中/READY/失败，引用数如无接口统计不得伪造；画板的“3处引用”为示例，首版在媒体库展示“引用保护中”，实际删除409后显示存在引用。不会提供无鉴权存储地址。
- 15分类标签：模块分类树最多两级，全站标签；新建和编辑使用完整资源ETag；删除有子项/引用时显示409信息，不提供强制删除。
- 16回收站：仅“恢复为私密”，不自动重新发布，无普通永久清空按钮；17导出备份：202进入任务跟踪，可重试失败；本地/校验/异地三项分开，恢复演练只读记录，不提供在线覆盖数据库按钮。
- 18双因素：密码之后TOTP或恢复码，输入错误给统一反馈；31密码页是第一步。登录链路由统一Auth.js集成，不将画板当作新增业务认证API。
- 19安全设置：MFA/恢复码状态，进入统一认证安全动作需重新认证；站点文案可单独编辑，保存需Settings ETag。20审计：必要操作摘要、时间、请求关联标识，不含正文/秘密。
- 21保存冲突：本地输入保留、比较差异、复制本地内容、载入服务器版本（载入前二次确认）。画板仅展示前两个主动作，载入动作在比较视图中。22为空，23为加载骨架，24为失败重试，25公开不可访问404，26会话过期保留编辑，27后台403/重新认证。
- M28手机后台抽屉：遮罩点击或ESC关闭，焦点圈定菜单，关闭回到触发按钮；公共手机菜单使用相同遮罩行为，内容为生活/知识/搜索，不能暴露管理私密数据。
- 29发布设置：期望权限/分类/标签/地址/摘要/封面，均保存至草稿，不能直接改变当前权限。桌面使用同内容的按需右侧栏，手机为独立全屏面板；选择后返回编辑不丢输入。
- 30生活记录编辑：标题、Markdown文字、图片说明，按统一草稿/发布协议；32生活记录详情补充短文图文布局，与长文章不同，媒体仍用placement授权读取。

## 4. 关键状态与交互契约

打开编辑：GET admin content与draft；dirty=false。修改后dirty=true→保存中→200更新ETag和时间、dirty=false。网络/500：保持dirty，重试保留输入；412：进入21，禁止强制覆盖；428：重新读取版本再由用户确认；401：26，登录返回后先比较版本；403：27；422：字段旁定位错误，保留其他输入。

发布面板打开时携带草稿及state ETag；确认提交后显示处理中，网络不明时不创建新键；成功显示正式发布序号和查看内容入口，PRIVATE发布则进入管理员预览而非匿名链接。失败412时需重新审阅最新线上状态；路径冲突409在地址字段旁提示；媒体未READY指出具体项（Problem.errors.pointer）。

转私密、撤回、删除、回收站恢复、历史恢复均需显式确认文案，说明会影响线上还是只改草稿；状态操作If-Match使用state ETag，历史恢复/手动快照用draft ETag。转私密不触碰正在写的正文；恢复回收站额外将期望权限置PRIVATE。

相册大图键盘左右翻页、ESC关闭，触屏可左右滑并保留按钮替代。抽屉/发布确认/灯箱 focus trap，关闭回原按钮；菜单aria-expanded，目录折叠aria-controls，状态反馈aria-live。图片有altText，纯装饰图空alt；触控重排支持上移/下移和读屏播报位置。加载骨架尊重减少动画，不闪烁，不以loading清除正文。

## 5. 异常状态覆盖规则

列表/搜索/媒体/分类/历史/回收站：23加载、22空、24失败可重试。详情：23加载、24失败、25不可公开；搜索无命中使用“没有找到相关记录”并保留关键词。编辑：保存中、失败、21冲突、26过期、27无权及离开未保存确认；媒体：处理中不可发布，失败允许重新上传；备份：三项分别可失败。所有成功提示以服务器确认结果为准。

## 6. 实现阶段核验

SVG/PNG仅完成静态视觉检视；真实字体、图片裁切、长标题、目录滚动、灯箱手势、软键盘、焦点/读屏、200%缩放、对比度与44px目标均待IV-05/08。桌面目录不可遮正文，手机固定操作条不可遮输入。示例日期/数量/版本/引用数不代表生产已有数据；实现时必须接有定义的数据源，没有来源的字段应省略而非显示固定假数据。
