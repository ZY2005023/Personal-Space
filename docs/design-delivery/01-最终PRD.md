# Personal Space V1.0 最终 PRD

版本 PRD-1.0｜2026-11-02｜状态：设计交付，非工程验收

## 1. 基线、证据与阅读顺序

产品是单管理员维护的个人数字花园，访客仅浏览公开内容。本包延续 2026-11-02 的规范级冻结，不重新扩展功能。来源为原聊天最终冻结记录和 DB-RC1；读取接口仅返回最近五轮且无更早游标，更早的 PRD/API 评审稿及完整视觉源文件未能读取。最终冻结记录优先于 RC1；本包补齐的 API 路径、字段长度、配色、尺寸、状态版本和引用表是“交付细化”，不冒称原对话已确认的逐字内容。产品语义如需改变，记录原因、五份文档影响及验收更新后再改基线。

五份文件依次为 PRD、数据库物理设计、OpenAPI YAML、页面原型/规范、测试验收标准。03 的 x-contract-rules 是 API 全局语义，02 第16–20节覆盖 RC1 中未收敛表述。00-交付说明记录静态检查结果及尚未执行事项。

## 2. 目标与范围

R-01 内容统一为 MOMENT（生活记录）、ARTICLE（生活或知识文章）、ALBUM（生活相册）；模块 LIFE/KNOWLEDGE。不开放注册、评论、社交、付费、多管理员、兴趣模块、AI 功能和独立搜索服务器。公众首页纯文字首屏，生活/知识入口、最新内容、精选照片；精选照片从有效公开相册读取，未有独立精选管理依据，本次以页面编排细化处理，不新增推荐系统。

R-02 前台包括首页、生活/知识列表、分类标签筛选、文章/记录详情、相册详情及大图、公开搜索、不可访问/空/错误页面。后台包括登录与 MFA、概览、内容列表、三类型编辑、发布确认、历史版本、媒体、分类标签、回收站、导出/备份任务、安全设置和审计。后台桌面左导航，手机抽屉导航。

## 3. 权限与认证

R-03 唯一管理员通过 Auth.js 统一认证，无平行会话或业务登录接口。登录先密码、再 TOTP/一次性恢复码；未完成 MFA 不可访问业务私密 API。公网使用 HTTPS，TOTP、恢复码及敏感操作重新认证通过后才可上线。敏感动作包括恢复码再生、MFA/密码修改、导出和手动备份，业务 API 需要短时重新认证证明；实际 Auth.js 版本和集成方式属于 IV-01。所有写入使用同源会话、CSRF 防护、Origin 校验；业务契约中的 cookie 是 Auth.js 会话的逻辑描述，生产 cookie 名由适配器映射。

R-04 公开谓词：PUBLISHED && PUBLIC && deleted_at为空 && published_revision_id非空。列表、搜索、详情、别名和派生媒体都在服务端检查；匿名无法区分私密/删除/不存在，统一 404。原图始终仅管理员可读。公开照片不能透露 EXIF 定位信息；正文 Markdown 服务端消毒。会话失效立即拒绝后台请求，保留本地未保存编辑供重新登录后手动恢复，禁止静默丢失。

## 4. 内容生命周期

R-05 创建：创建身份与独立草稿，PRIVATE+NEVER_PUBLISHED；草稿可不完整。保存仅改变草稿和草稿引用；保存成功有明确时间与新 ETag。失败保持输入，不显示“已保存”。关闭含未保存更改的页面要提示。交付不擅自引入自动保存周期；前端可在实现时确定保存节流，但不能绕过条件校验。

R-06 三种编号独立：工作草稿 revisionNumber；所有不可变快照 versionNumber；正式发布 publishedEditionNumber。另以 stateVersion 保护权限与线上状态变化。两个标签页同版本保存，一次成功，另一次 412；界面提供比较/复制本地内容/载入服务器版本，无无条件覆盖按钮。

R-07 发布必须先保存，显示标题、目标路径、期望可见性、媒体准备状态、草稿版本及当前线上版本摘要；管理员明确确认后提交。If-Match 检查草稿 ETag，expectedStateEtag 检查线上状态（含首次发布无指针的状态），两个条件都在同一事务重查。新快照、三层引用、主指针、投影、路由、搜索、审计、outbox 和幂等结果原子提交，正式发布一律 200。发布后草稿基线和草稿 ETag推进；重复请求不再增版本。

R-08 转私密立即阻止新的匿名读取，保留未完成草稿，不自动发布；撤回设 UNPUBLISHED+PRIVATE。历史 URL 不可绕过权限。再次公开必须重新发布确认；已获取的图片或正文无法远程收回，但新的匿名授权不能依赖旧缓存成功。没有静态公开原图链接或可在撤销后继续授权的长期签名 URL。

R-09 手动快照保存当前草稿的完整可恢复内容，不改变线上。恢复历史仅替换工作草稿并更新其 ETag，线上不变。软删除进入回收站、停止公开；回收站恢复后 PRIVATE，曾发布为 UNPUBLISHED，从未发布仍 NEVER_PUBLISHED，草稿期望权限也改 PRIVATE。历史不被普通删除操作清除；永久清理为专用维护流程，本包不提供普通清除入口。

## 5. 分类、路由与媒体

R-10 分类最多两级、父子同模块、根名/slug 也唯一；标签全局标准化唯一。工作草稿修改分类标签不改变线上。重命名是全站分类管理动作，历史保留当时名称；更新名称后同步当前查询投影，避免搜索名称与前台显示不一致。有任何草稿、历史、发布引用时禁止删除分类/标签。

R-11 路径统一注册，规范和别名全局互斥；改路径在发布时生效，旧地址单次 308 至当前规范路径。不可公开时旧地址返回 404。路径规则详见 02/03；未发布草稿不预占路径，发布冲突需在发布面板反馈。删除路径占用不释放给其他内容。

R-12 媒体状态 UPLOADING→PROCESSING→READY/FAILED，发布只能引用 READY 媒体。原图受保护，派生图清理敏感元数据。每次出现有独立 placementId，同媒体可重复。初次按可信拍摄时间升序，缺时间按稳定上传顺序；手动排序持久化，后续新增追加。相册封面规则网格、详情自由布局、大图预览。每项说明/替代文本随快照保存；触屏排序另有上移/下移按钮，不仅依靠拖拽。

R-13 媒体删除须无草稿、历史和当前引用；共享图不能随一篇内容删除而消失。封面与正文引用都要追踪。默认图片限额、可接受 MIME 白名单、像素上限是 IV-08 的上线配置阻断项，未获旧记录依据，不伪造已冻结数值。上传返回 202 任务，客户端轮询状态；失败重试不会创建重复资源。

## 6. 搜索、任务与数据保护

R-14 PostgreSQL 中文搜索覆盖标题、摘要、分类、标签和正文，只搜当前有效公开版本。1–2 字有独立路径，长词可用 pg_trgm；输入为空不执行全量搜索。列表使用稳定游标，不因相同发布时间漏项。排序相关性及索引执行计划 IV-03，未实测前不宣称搜索性能达标。

R-15 导出和备份创建 202+jobId，按任务查询。任务可重认领、有界重试、租约防旧执行器写回。导出包含草稿/历史/元数据/媒体清单，下载需管理员鉴权和有效期；不得导出密码/TOTP/会话密钥。恢复备份需要独立、加密保存的密钥材料和恢复手册。

R-16 分级备份保留 DAILY/WEEKLY/MONTHLY/YEARLY/MANUAL，数据库+必要媒体+清单形成一致性点。本地成功、完整性校验、异地副本分别显示；不能用绿色总状态掩盖异地失败。每三个月及首次公网前做完整恢复演练。频率具体时刻、保留数量、异地目标和 RPO/RTO 在可读取记录中缺失，列 IV-07，必须在实现配置和上线验收前落定。

## 7. 页面与非功能要求

R-17 桌面文章极简阅读、顶部进度、知识目录；手机折叠目录单栏。编辑器桌面左右编辑预览、设置栏按需；手机编辑/预览切换、独立发布面板。所有页面覆盖加载、空、失败；编辑覆盖 412、428、未保存、会话过期；公开无权限统一 404，后台 403 显示明确动作。04 提供 1440 与 390 两套可编辑 SVG 画板和尺寸规范，属于静态设计，不是运行中的网站或已完成的 Figma 文件。

R-18 触控目标至少44px；文字对比目标 WCAG AA；键盘焦点可见，目录、抽屉、弹窗、大图可键盘操作；关闭弹窗返回触发焦点；减少动画偏好生效。360–430手机、768平板、1024及以上桌面实测为 IV-05。性能预算需在设备/数据量确定后写入 IV-08；安全、无数据丢失、无越权是无条件阻断项。

## 8. 交付与变更门槛

设计门槛：五份文件存在，API结构与引用检查通过，核心规则有数据库/API/页面/测试映射，未验证事项不混入已通过项。当前仅可判定“静态设计交付”，不是可以上线。

工程门槛：IV-01～08逐项提供证据；通过 05 全部 P0/P1、真实迁移/回滚/恢复、权限/并发/缓存测试、真实设备验收。未授权开始应用开发、建库、迁移或部署。未知备份/上传/性能参数必须有单独决策记录，不能自行当作旧基线。
