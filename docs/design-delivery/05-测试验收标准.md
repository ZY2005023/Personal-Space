# Personal Space V1.0 测试验收标准

版本 QA-1.0｜2026-11-02｜本文件为可执行用例说明，所有运行结果均为“未执行”。

## 1. 门槛与证据规则

P0 为安全/数据完整性上线阻断；P1 为核心功能与页面上线阻断。本包没有把未知性能指标写成通过条件。IV-01～08 的未定参数必须先记录决策，再补齐环境和边界值；不能仅凭本文件签字上线。

设计静态检查：YAML解析、OpenAPI 3.1结构校验、本地引用解析、operationId唯一、路径参数完整、schema正反例、条件/幂等/CSRF覆盖及规则映射，见06。静态检查不执行任何API，也不能证明事务、授权、页面交互或恢复已经可用。

实现测试环境：隔离数据库/对象存储、两名义客户端但同一管理员、匿名客户端、可控时钟、两个执行器、网络超时及事务故障注入。禁止在真实公开内容上做破坏性用例。构造MOMENT/ARTICLE/ALBUM、LIFE/KNOWLEDGE、公开/私密/撤回/回收站、同时间记录、中文短长词、共享图与重复placement、带EXIF及伪造MIME素材。

每例证据包括构建版本、环境、数据种子摘要、脱敏请求/响应及requestId、数据库前后关系断言、必要截图/日志、实际结果、责任人、执行日期。不能只以HTTP200判定成功。每例重置夹具；并发场景必须保留重现时序。

## 3. 实现阶段验证清单

- IV-01：锁定Auth.js版本、提供方路由、adapter物理表、cookie/CSRF映射；密码+TOTP+恢复码、防重放/限速/会话撤销、敏感操作重新认证整体验证。责任：后端/安全；T-01～05、48。
- IV-02：锁定PostgreSQL与Prisma，实际迁移创建/回滚验证；组合FK、根分类唯一、延迟触发器、快照只读权限。责任：后端/数据库；T-09、24～26、46、48。
- IV-03：中文1–2字与长词、相关性、分页一致性、实际数据量执行计划；数据集规模和响应预算先签定。责任：后端/测试；T-27、35、36。
- IV-04：原图保护、逐请求媒体授权、URL与缓存撤销、Markdown消毒和导出下载；公网渗透/越权检查。责任：后端/安全；T-06～08、20、32、38。
- IV-05：真实手机/桌面/平板、字体回退、Markdown长文、键盘与触屏排序。责任：前端/设计；T-31、41、42、44、47。
- IV-06：事务失败注入、双版本并发、幂等响应丢失重试、租约fencing/outbox去重，重试次数及退避先确定。责任：后端/测试；T-10～19、21～23、28～30、33、37。
- IV-07：具体分级备份频率/保留数、异地目标、加密密钥保管、恢复工具版本、RPO/RTO先记录；首次公网前及每季度完整恢复演练。责任：运维/管理员；T-39、40、45。
- IV-08：MIME/大小/像素限额、上传异常、低端设备/真实数据性能预算与WCAG AA/触控目标实测。责任：全栈/测试；T-34、43、44。

## 4. 发布判定

所有P0/P1通过且有证据；安全认证/HTTPS/TOTP和恢复码验收完成；无未解决数据丢失、越权、半发布、错误恢复、备份缺失；五份文档与最终实现变更一致；IV-01～08全部关闭或给出不降低冻结要求的已验证替代方案。任何新需求或核心语义变化必须更新PRD、DB、API、UI、测试并记录设计变更。当前全部工程用例未执行，不能进行公网发布。
