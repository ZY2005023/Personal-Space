# N3：分类标签与图片处理基础

日期：2026-11-02。没有创建数据库、迁移、管理员、存储桶或部署。

## 本批交付

- `/admin/taxonomy`：分类和标签切换、新建、读取最新版本后编辑、删除、明确错误反馈。沿用现有移动端表格和表单样式；编辑期间禁止切换目录。
- 后台 categories/tags 的 GET 列表/详情、POST、PUT、DELETE。列表使用创建时间与UUID降序的数据库键集分页，签名游标绑定目录；DTO不暴露内部标准化名或删除标记。列表与详情提供强ETag。
- 名称使用NFKC、去首尾空白、折叠空白、拉丁小写去重。分类同级名称/slug保留，标签全站唯一；软删除不释放名称。根分类空父键唯一性暂由目录事务锁及服务端检查补足，物理部分唯一约束仍待实施。
- 分类最多两级、父子同模块、防循环；系统分类禁止改删。有子记录的分类不能降级；有草稿/历史/发布引用或子分类时不能删除。跨模块移动也先检查所有引用，已删除子记录同样阻止跨模块移动。
- PUT/DELETE要求完整资源ETag；缺失428、过期412、弱/通配标识400。POST/DELETE幂等键锁、响应重放和审计在同一事务内。DELETE成功204无响应正文，客户端已兼容。
- 重命名在同一事务内更新关联当前搜索文档的分类/标签文本；先按ID锁搜索文档，再读取最新目录名称。不会锁内容行或覆盖正文/标题。公开SQL按当前版本的分类/标签ID叠加现名，数据库历史快照保留原名。
- 编辑器发布设置加载分类与标签目录；选择仅修改工作输入，保存/发布仍走原有独立版本与引用事务。
- `image-processing.ts`：静态JPEG/PNG/WebP魔数及声明类型核对、10MiB与2400万像素限制、拒绝SVG/动画/APNG标记、方向校正、长边480/2560的WebP质量82派生，不放大小图。默认剥离元数据并检查实际产物，原输入缓冲区不改写；解码超时20秒。限制为当前工程默认，尚未做真实服务器资源调优。

Sharp调用参照官方[输入元数据](https://sharp.pixelplumbing.com/api-input/)、[输出选项](https://sharp.pixelplumbing.com/api-output/)及[缩放](https://sharp.pixelplumbing.com/api-resize/)文档。本模块是后续Worker的构件，当前请求不会调用它，也不会返回虚假的上传成功。
