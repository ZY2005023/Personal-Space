## 真机复验步骤

使用已初始化的隔离测试环境和测试账号。手机或平板先连接到可访问该环境的测试地址。Android Chrome 可通过 USB 调试端口转发访问电脑的 3000 端口。iPhone 或 iPad 可使用设备可达的私有 HTTPS 测试地址。管理员操作使用测试内容和图片。

1. **T-31 相册排序。** 在后台创建测试相册，在「内容图片」多选三张已就绪的照片，包含可用拍摄时间与无拍摄时间的照片。确认可信拍摄时间按升序追加，其余按上传顺序。用触屏点「上移」「下移」，保存后重开页面，确认顺序仍在。开 VoiceOver 或 TalkBack 后重复，预期播报图片和更新后的位置。
2. **T-41 手机与平板布局。** 在手机竖屏和平板横竖屏依次打开首页、列表、长文章、相册、后台和编辑器。滚动长文章，点目录跳转，打开相册大图并左右滑，切换编辑和预览，保存一份草稿并打开发布确认。预期正文和页面操作无横向溢出，缺少首选字体时中文仍可读，手机可切换编辑和预览，大图可滑动和按钮翻页。
3. **T-43 键盘、读屏和减少动画。** 打开系统减少动画偏好。用 VoiceOver、TalkBack 或 NVDA 打开菜单、目录、发布确认和灯箱，再关闭。用桌面键盘重复，用 Tab 检查焦点，用 Escape 关闭弹窗。预期名称、状态和排序位置可听到，焦点留在打开的模态窗口内，关闭后回到触发控件，滚动和过渡符合减少动画偏好。
4. **T-44 触控、缩放和对比度。** 在桌面浏览器设置页面缩放为 200%，检查阅读、后台表格、编辑表单和操作条，再在手机上点同类控件。预期正文无主体横向溢出，控件可操作，表格必要时只在自身区域滚动。检查明暗主题普通文字、链接和错误状态，代表性普通文字对比目标至少 4.5:1。
5. 回报设备型号、系统、浏览器、对应验收编号，以及失败时的页面、步骤和实际表现。测试账号凭据保留在本机。
