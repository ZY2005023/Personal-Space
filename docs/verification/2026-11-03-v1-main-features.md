# N18：第一版主要功能源码闭环

2026-11-03。延续此前主要功能，实现本轮导出、备份、调度、清理和隔离恢复链路。主要源码已接齐，真实接库验收尚未完成。

## 本批新增

1. 导出：私有本机不可覆盖归档，EXPORT_CREATE重新认证用途，创建任务与幂等结果/审计同事务，通用任务查询、到期鉴权下载及下载后错误响应，Worker命令。
2. 备份：BACKUP_CREATE用途、手动创建记录，pg_dump PostgreSQL18重复读导出快照，必要原图/活动派生、六表行数和SHA-256清单，本地读回与pg_restore --list检查，restic备份与check --read-data；异地失败保留本地成功，重试复核本地bundle后续传。
3. 调度：明确配置BACKUP_AUTOMATIC=true才启用，按香港时区生成最近到期的日/周/月/年周期，周期键去重。不执行自动forget/prune/保留量删除。
4. GC：只有显式配置宽限期才运行；软删除、三层无引用、过宽限期后删除原图及登记派生，记录MEDIA_PURGED审计。导出/备份在建立快照前持共享media:gc事务锁，GC持独占锁。孤立未登记对象扫描与过期归档文件物理清理另留维护工作。
5. 恢复：独立CLI默认仅核验bundle，显式--execute才在独立现有空PostgreSQL18和独立私有桶演练，单事务恢复、不可覆盖媒体写入、读回校验、六表计数/内容引用检查，并写PASSED/FAILED。没有在线覆盖数据库的恢复API。
6. 界面：后台导出/备份表单、原图选项、密码/验证码或恢复码、任务轮询、可保留任务链接、失败/过期提示、ZIP下载与备份详情；会话过期有重新登录入口。

安全扩展契约从0.2.0到0.3.0，新增两个用途，仍8个端点/80处引用。业务契约保持1.0.2，36路径/49操作/558引用。无新增模型或运行依赖。PostgreSQL/restic工具命令依据与运行细节见[运行说明](../OPERATIONS.md)。
