# N5：管理员安全

日期：2026-11-03，Asia/Hong_Kong。

## 交付

- TOTP计算从手写HMAC/Base32替换为otplib13.6.0，保留RFC向量、6位/30秒及最多前后一步时间窗。
- 登录与重新认证复用credentials-store，Argon2id密码校验、TOTP步骤及恢复码在事务中原子消费；登录尝试计数独立提交，失败业务事务不能消掉次数。未知用户名仍进行密码哈希校验，不声称已经证明严格恒定响应时间。
- 新增SecurityChallenge模型，总模型30；只有客户端类型生成和静态校验，没有建表或迁移。摘要、用途、会话、会话版本、到期与一次性消费由服务端校验。
- 7个同一Auth.js会话下的安全动作：再次验证、改密、恢复码轮换、撤销会话、MFA开始/确认/取消。Origin与会话CSRF校验共用同一函数。
- 安全页面无浏览器持久化凭证，成功恢复码只在当前页面展示。新MFA确认前原验证器不变，取消立即作废绑定凭证。密码/MFA/恢复码变更撤销旧会话并追加无凭据的审计。
- 单管理员退出通过Auth.js signOut事件撤销对应版本的全部会话，按钮明确标为退出全部设备；旧退出令牌不推进更新版本。
- 本机初始化脚本默认帮助，需要--create、交互终端及额外文字确认。只有验证实际TOTP才创建固定singleton_key=1的管理员，最终事务再次确认管理员表为空。无HTTP注册入口、默认密码或自动建库。
