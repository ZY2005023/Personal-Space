# N13：公开浏览流程补齐

2026-11-03。本批连续完成访客筛选、目录续页、错误恢复、卡片/阅读页导航和回归检查。没有创建数据库、迁移、管理员、存储或部署。

## 页面与交互

生活、知识、相册和搜索均接入categoryId/tagId。生活/知识类型标签保留目录条件，改变类型从第一页开始；相册固定LIFE/ALBUM。搜索支持模块/类型与目录联合筛选，切换知识模块时清除已选的不兼容类型并禁用记录/相册选项。

GET表单无需写接口；分页保持q/module/type/categoryId/tagId，清除筛选回到页面默认状态。目录首批20项由服务端有界查询，客户端显式加载更多，沿用公开目录签名游标；未在当前已加载选项中的选择仍保留为“已选分类/标签”。目录只展示公开API允许的项目，模块列表过滤其他模块分类，搜索允许跨模块目录。

加载更多校验UUID、响应数组与游标长度、hasMore/cursor一致性及重复游标；按ID去重合并，更新目录现名。防止并发重复请求，卸载取消，10秒超时后可重试。单个目录首次读取失败不会阻断已有内容，保留选择和重试入口。无JavaScript时首批筛选仍能通过GET提交，但目录续页与搜索类型联动需要JavaScript；服务端仍验证所有输入。

统一识别重复参数、非法UUID/模块/类型、页面范围覆盖、超长搜索词及游标；不再把重复值任意取一个或静默截断搜索词。无效参数显示重新浏览入口，失效游标显示保留有效条件的第一页链接。页面返回可恢复说明（HTTP200），API的400语义不变。搜索词NFKC标准化与修剪，与数据库匹配规则保持一致。

内容卡片与所有阅读类型的标题区提供分类/标签链接，目标为所属模块列表；显示发布读取叠加的目录现名，不改写历史快照。分类标签使用React转义，筛选值使用URLSearchParams，分页游标不进入新的筛选链接。空目录不生成空导航；筛选无结果和未有记录使用不同说明。
