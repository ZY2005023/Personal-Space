# N11：内容状态事件与搜索投影修复

2026-11-03。本批没有创建数据库、迁移、管理员、存储或部署，没有运行真实Worker处理模式。

## 实现

Outbox认领白名单增加CONTENT_STATE_CHANGED，沿用1分钟租约、同令牌锁内检查、最多5次有限重试及事务确认。MEDIA_DELETED行为不变，未知事件不被认领。

内容事件严格验证stateVersion/revisionId，拒绝额外字段、未来状态版本及与当前同版本但不同指针的事件。旧版本事件只作修复触发，不提供搜索正文、权限或目录名称；旧revisionId不会被查询。事务先锁内容，读取当前状态；内容不存在、私密、撤回或删除时清理其搜索文档，无需读取快照。公开内容必须有有效当前发布指针及时间，仅按contentId+revisionId+PUBLISHED读取一个快照，校验结构及模块/类型一致性。

按content -> categories -> tags -> search顺序锁定，读取目录现名构造搜索字段，不把历史目录名称覆盖到当前投影，也不修改历史快照。缺失目录、缺失/损坏快照等拒绝写入并按现有策略重试；事件数据不可用于直接提供对象路径或正文。投影修复与事件PROCESSED确认同一事务，确认失败回滚投影。不会推进内容状态版本、草稿、发布编号或重写引用。

现有内容事务仍同步更新搜索；本处理器用于事件重放与投影修复，不是权限授权依据。公开查询仍关联当前发布指针并检查公开谓词，不能依赖Worker及时性授权。分类/标签改名沿用同步投影更新，不新增目录事件。消费者只修复已有事件关联的内容，不是全库搜索索引重建或中文检索性能方案。

## 验证

全量152项测试通过，新增8项覆盖旧事件只读取当前快照、私密/撤回/删除/缺失清理、非法/未来/同版本冲突事件拒绝、缺失指针/快照/错误类型、目录现名及缺失引用、确认与投影原子提交、确认失败回滚重试、状态推进后旧事件不恢复旧投影。生产构建（含TypeScript）与契约结构/引用校验通过。无模型、依赖或API契约变更；工作契约仍1.0.2，36路径/49操作/558引用，安全扩展8操作/80引用。

HTTP入口未改，本批未重跑HTTP，沿用N9的52项HTTP与认证拒绝记录。测试使用内存事务替身，不证明真实SQL/隔离级别、死锁或数据库故障恢复。IV-02/03/06仍需真实多Worker、目录改名与发布交叉、租约接管、锁等待及提交结果不明重试验证。GC保留/备份保护、导出和备份恢复仍未完成。
