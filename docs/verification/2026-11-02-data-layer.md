# 数据模型、引用保护与公开查询改造记录

2026-11-02 · N2代码批次。没有创建数据库、迁移、管理员或部署。

## 本轮完成的代码

- Prisma模型从13个补至29个，新增媒体派生、三层媒体引用、分类标签三层引用、搜索投影、任务/Outbox、备份/副本/演练和站点设置；补充同内容版本组合FK、父分类同模块FK、引用/顺序唯一及RESTRICT关系。
- 时间精度统一TIMESTAMPTZ(3)，与Node Date和签名游标精度一致；PostgreSQL高级约束实施清单见[CONSTRAINTS.md](../../prisma/CONSTRAINTS.md)。这些定义没有转成或执行迁移。
- 保存草稿同步draft_media/categories/tags；新快照仅追加revision_*；正式发布同步content_media/tags/publications及公开搜索；转私密、撤回或软删除在同一事务中清除公开搜索；必要访问状态事件写Outbox。
- 引用校验检查分类模块、软删除、标签、媒体归属与状态；保存草稿可引用待处理图，发布/历史恢复要求READY；服务端生成分类标签名称快照，历史不随改名重写。
- 删除前检查服务覆盖草稿、历史、当前发布及分类子节点，资源行锁与创建引用共用。媒体/分类删除路由及实际对象GC仍未接通，不能据此声称已可从页面删除文件。
- 变更不再使用一个全局内容锁；相同幂等scope/key先串行，再按内容行/草稿行/分类标签/媒体/路由锁序操作。恢复回收站仍默认私密。
- 公开读取移至public-store，SQL只JOIN当前主指针的发布快照、规范路径及匹配该指针的搜索投影，不读取工作草稿和全部历史。详情按ID/path单项读取；公开列表和搜索在数据库内筛选、相关性排序与游标分页。公开目录按当前公开引用筛选。
- 真实公开读取使用只读事务及2秒statement_timeout；仍需实测查询计划。当前基础包含匹配尚未完成pg_trgm索引及专门短词优化，不宣称中文搜索性能达标。
- CURSOR_SECRET从AUTH_SECRET分离，生产分页必须显式配置；游标加入格式/排序版本与相关性，绑定筛选。旧游标返回400，重新载入首页即可。
- 首页的最新/相册分开限量查询；模块、搜索、相册页面使用相同查询服务和分页链接。本地只读样例继续使用内存适配器，生产不启用样例。
