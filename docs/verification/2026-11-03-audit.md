# N14：审计记录

2026-11-03。将后台原先固定读取最近50条的占位列表改为独立页面，接通工作契约已有的GET /admin/audit-logs。

## 功能

接口支持既有limit/cursor，默认20条、最大100条；按createdAt和UUID倒序键集分页，查询limit+1生成下一页。返回契约规定的id/action/targetType/targetId/requestId/createdAt，日期ISO格式；复用统一管理员会话和分页签名。

后台/admin/audit直接读取同一服务，支持action操作关键词（忽略大小写）与清除筛选；页面筛选是内部能力，未给API添加未声明参数。翻页保留操作条件，切换筛选返回第一页。游标关联管理员与操作条件。页面显示香港时区时间、中文常见操作名、原始操作标识、目标及请求ID；没有数据和失效条件都有可用入口。新增页面沿用后台移动布局，长标识可折行。原动态占位页只保留尚未接通的备份部分。

本批不写入、修改或清理审计数据，没有添加新模型、依赖、队列或配置。
