# N9：公开分类与标签分页

2026-11-03。本批只修改工程源码与记录，没有创建数据库、迁移、管理员、存储或部署。

## 实现范围

公开 GET /categories 和 /tags 已按工作契约已有的 limit（默认20，1至100）和 cursor 返回 data/meta。移除全量目录读取及固定 hasMore=false 的响应。每次SQL最多取limit+1，额外一项用于判断下一页。

分类继续按sort_order、UUID升序，标签继续按created_at、UUID降序。分类游标将有符号32位排序值可逆映射为非负数，使用既有HMAC签名设施；时间占位和排序数值范围严格验证。标签使用创建时间，不因改名更新时间改变位置；内部createdAt不进入响应。游标绑定公开目录命名空间、目录类型及排序版本，允许改变分页大小，拒绝跨目录/内容游标、篡改和无效UUID。

查询仍校验目录未删除，且存在指向当前正式快照的公开、未删除内容；不读取草稿、旧快照正文或私密引用。沿用只读事务和2秒statement_timeout。空库/本地只读预览返回空页，但仍先验证游标；预览不伪造目录数据。

分类排序值可被后台修改，翻页期间公开引用也可改变；这不是跨请求数据库快照，不承诺并发修改时零遗漏。已发出的游标携带边界值，不依赖边界行继续存在。
