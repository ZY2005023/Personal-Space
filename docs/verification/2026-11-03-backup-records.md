# N16：备份与恢复演练记录

2026-11-03。本轮先完成[N15站点设置与阅读页信息](2026-11-03-site-settings.md)，再连续完成备份记录读取与页面。没有创建数据库、迁移、管理员、存储或部署。

## 备份读取

接通既有GET /admin/backups、GET /admin/backups/{backupId}和GET /admin/restore-drills契约。统一管理员认证，返回摘要及分页，不执行备份或恢复。

备份列表按关联OperationJob的创建时间和备份ID倒序分页，因此尚未开始、startedAt为空的PENDING记录也能正常翻页；恢复演练按startedAt/ID倒序。均默认20、最大100，读取limit+1。签名游标区分管理员与备份/演练命名空间，非法游标400；详情UUID标准化，不存在404。备份属于单管理员系统级记录，模型没有独立owner字段，不虚构所属关系。

只选择契约摘要字段：备份ID/任务ID、类型、整体状态、本地状态、完整性状态、异地状态及时间；关联任务创建时间只作内部排序，不返回。演练notes为空时返回契约需要的空字符串。没有返回备份路径、原始任务payload或内部验证清单。

## 页面

/admin/backups取代旧动态占位页，提供备份记录与恢复演练切换、空状态、签名游标分页和失效恢复。/admin/backups/{id}显示三项状态、完成/校验时间和关联任务ID。演练列表可跳回相应备份。时间以香港时区显示，长标识可折行，手机行显示三项状态的文字标签。

整体任务状态以文本辅助显示，本地/完整性/异地分别显示状态；异地FAILED不会被整体SUCCEEDED覆盖。页面明确当前只能查看已有记录，不提供尚未实现的创建/恢复按钮。
