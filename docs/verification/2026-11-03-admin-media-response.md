## 修正

后台派生预览原先在读取对象后仅复查媒体是否READY。现在同时重新查询唯一活动且metadataSanitized的派生版本，比较ID、对象key、处理版本、大小及MIME。读取期间替换、停用、重复活动行或媒体转处理状态，均404拒绝返回已读取字节。

原图下载先检查登记大小在现有上传限额内，再按登记大小作为对象读取上限；要求originals/mediaId命名空间并校验大小、SHA256。读取后再次按mediaId/管理员归属/未删除条件查询，比较原图key/大小/摘要，变化时404。派生图也要求variants/mediaId命名空间；UUID转小写再校验，保持合法大小写请求等价。

原图仍以application/octet-stream附件下载，文件名RFC5987编码，派生图仍image/webp；统一private,no-store和nosniff，不跳转存储URL。改动没有引入媒体写入或GC。注入读取接口仅供服务端测试，HTTP不接受适配器参数，认证/Origin入口不变。
