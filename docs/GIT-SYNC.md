# GitHub版本保存与每日同步

目标：[ZY2005023/Personal-Space](https://github.com/ZY2005023/Personal-Space)，分支main。仓库为公开项目。

同步范围为项目源码、契约、设计文档、测试和必要配置示例。node_modules、.next、work、生成客户端、真实.env、私钥、运行数据、媒体原图和备份不进入版本库。初始提交与后续日常提交均检查暂存区的常见凭据模式；该检查不能代替对新增私人文件的人工判断。

每日计划时间为香港时间22:30，在本机执行，需要项目、Git登录和网络可用。没有文件变化且没有尚未推送的提交时安静结束，不创建空提交。已有本地提交未推送时仍会推送；这是远端尚未同步的更新。

执行脚本：`node scripts/sync-git.mjs`。`--dry-run`只检查本地状态，不提交、推送或fetch。

脚本只允许指定origin及main；先fetch检查远端历史，再检查/提交本地变化并推送。遇到远端未合并更新、冲突、进行中的合并/rebase、错误仓库、非main分支、凭据检查或认证失败时停止。不会强推、改远端、自动合并/rebase、切分支、reset、stash或清理文件。日常任务不开发功能、执行数据库迁移或部署。

提交作者使用本机登录的ZY2005023及GitHub公开的noreply地址，仅设置本仓库身份，不修改全局Git身份，不在脚本或远端URL中保存令牌。

任务由本地Codex调度；调度是否处于启用状态以应用中的任务状态为准。任务在电脑不可执行时无法同步，不能替代异地数据库/原图备份。
