# Personal Space V2.0 产品定稿

状态：用户已确认，范围冻结。日期：2026-11-11。兴趣专题与 AI 摘要建议为第二版的完整功能范围。本文作为后续开发、验收和范围变更的依据。

## 目标

访客可以按兴趣主题发现站主整理的公开内容。站主可以在后台整理兴趣专题，并用 AI 为文章草稿生成可编辑的摘要建议。

## V2-01 兴趣专题

- 前台新增「兴趣」入口及专题列表。专题详情展示标题、简介和站主手动排序的内容卡片，卡片沿用已有文章、生活记录和相册样式。
- 后台支持新建专题、修改标题和简介、排序、选择已有内容、设为公开或撤回。新专题默认私密。专题使用唯一地址标识，公开后地址固定。
- 专题保存内容 ID，每次访问读取当前公开版本。成员转私密、撤回或进入回收站后立即从专题隐藏。专题撤回后，旧链接返回 404。空专题显示明确的空状态。
- 专题不创建新的内容类型。文章及相册的草稿、历史、发布和权限沿用第一版规则。

验收：管理员能完成创建、排序、发布和撤回。访客能从导航进入专题及其条目。公开后改动成员顺序可见。成员转私密或专题撤回后，匿名访问无法读到相应内容。

## V2-02 AI 摘要建议

- 在文章编辑器内加入「生成摘要建议」。管理员主动点击后，用当前工作草稿的标题和 Markdown 正文生成一段简短中文摘要。
- 输入只包含本篇文本，排除原图、附件、账户信息和其他文章。调用前明确提示文本会发送到配置的 AI 服务，由管理员选择是否发送。
- 建议在独立区域显示。管理员可编辑、采用或丢弃。采用只填写当前编辑器的摘要字段，仍走已有的保存和发布确认流程。已填写摘要在采用前继续保留。
- 服务未配置时提供明确提示，手写摘要仍可用。超时、失败或取消时保留现有输入。密钥只在服务端使用，日志不记录正文和生成内容。
- 实现时再选服务商和模型，并配置请求超时、输入长度与用量上限。验收可用测试适配器，启用真实服务前另测一次实际调用。

验收：有权限的管理员能生成、编辑和采用摘要。匿名用户无法调用。采用前后分别验证草稿、正式发布版本和公开摘要的状态。模拟超时和服务未配置，确认原摘要和输入保留。

## 范围与发布

本版只交付兴趣专题和 AI 摘要建议。兴趣打卡、公开 AI 聊天、自动发布、自动标签和 AI 搜索留待后续需求确认。

第一版的手机兼容、备份恢复和上线验收仍按原清单收尾。本定稿将 V2 作为独立开发范围。首次上线是否包含 V2 由用户决定。若包含，两版的验收均通过后再一次性发布。

进入开发前按本稿补齐页面、数据库与 API 变更。交付时提供以上验收证据，并回归第一版公开权限、草稿保存和发布流程。
